# 🗡️ 픽셀 던전 나이트 (Pixel Dungeon Knight)
> **마왕성 탈환: 16비트 레트로 도트 방치형 RPG 웹게임 (v2.5 대규모 확장 패치)**

HTML5 Canvas & Web Audio API 기반으로 제작된 싱글 파일 브라우저 방치형 RPG입니다.  
별도의 백엔드 서버나 복잡한 설치 없이 브라우저 자체 로컬 스토리지(`localStorage`)와 암호화 백업을 지원합니다.

---

## 🎮 주요 게임 시스템 및 최신 업데이트 내역 (Features & v2.5 Changelog)

1. **5,000 스테이지 & 50대 테마 던전 대확장**
   - **50개 대구역 (총 5,000 스테이지):** 슬라임 초원부터 시작하여 고대 유적, 마왕성, 시공간의 틈새, 성운 요람, 망각의 도서관, 나락 계곡, 카오스 소용돌이, 퀀텀 넥서스, 판테온을 거쳐 스테이지 5000 최종 종착지인 **'세계의 정점: 오메가 특이점'**까지 구현.
   - **5,001+ [COMING SOON] 암시:** 5000 스테이지 정점 돌파 시 차기 대규모 차원 확장 업데이트 암시 및 전체 스테이지 모달 51구역 티저 카드 제공.
   - **스테이지 탐색 모달 최적화:** 5000개 스테이지를 50개 구역(구역당 100개 스테이지) 드롭다운과 퀵 점프로 렉 없이 즉각 탐색 및 이동 가능.

2. **초월 장비 동일 장비 제물 각성 시스템 (Awakening)**
   - 최고 등급인 [초월] 등급 장비는 동일한 초월 장비를 제물로 소모하여 **최대 5단계까지 초월 각성**이 가능합니다.
   - 1각성(동일 장비 1개), 2각성(2개), 3각성(3개), 4각성(4개), 5각성(5개) 필요.
   - 각성 1단계당 기본 장비 능력치가 +50%씩 복리 급증합니다.

3. **8대 고대 성유물(Relic) & 보유 패시브 시스템**
   - 별도 장착 없이 **보유만 해도 영구 지속 효과가 중첩 적용**되는 8가지 고대 성유물 추가:
     - 🗡️ **전쟁신의 파괴도:** 최종 가하는 피해량 폭증
     - 🛡️ **영겁의 생명 방패:** 최대 체력 대폭 증가
     - 🎯 **태고의 치명 안광:** 치명타 피해 대폭 증가
     - 💰 **미다스의 황금 성궤:** 골드 획득량 증가
     - 💎 **대마법사의 보석 나침반:** 보석 획득량 증가
     - ⚡ **질풍의 헤르메스 신발:** 공격 속도 증가
     - 🩸 **불사조의 심장:** 초당 체력 회복량 증가
     - 🌌 **시공간 왜곡 모래시계:** 스킬 쿨타임 감소
   - **유물 강화:** 동일 유물 복제본(1강 1개, 2강 2개, 3강 3개...)을 재료로 단계별 무제한 강화 가능.

4. **소환(뽑기) 탭 세분화 및 직관적 팝업**
   - **[장비 소환] / [유물 소환] 하위 탭 분리:** 장비와 성유물을 목적에 맞게 선택 소환.
   - **소환 레벨 시스템:** 소환할수록 소환 경험치가 쌓여 소환 레벨(Lv.1~10)이 상승하며 상위 등급 획득률 증가.
   - **등급별 확률 보기 & 장비 강화 모달:** 화면 중앙 집중형 팝업 모달로 보유 재화와 상세 수치를 한눈에 파악.

5. **인플레이션 밸런싱 & 인벤토리 역순 정렬**
   - 장비 인벤토리와 유물 보관함에서 **높은 등급(초월, 신화, 전설)이 아래쪽에 배치**되어 직관적인 등급 상승 체감을 제공.
   - 치명타 확률(Crit Rate) 스텟 강화 100% 상한선(MAX) 보호 적용.
   - 버서커 광폭화 스킬 효과를 '공격속도 + 치명타 피해 폭증'으로 리워크.

6. **레트로 도트 & 편의 시스템**
   - 간결한 화면 중앙 플로팅 토스트(알림 가림 최소화).
   - AMOLED 번인 방지 절전 모드(🌙), 전체화면 모드(⛶), 무손실 암호화 백업 세이브(PDK-ENC).

## 🚀 GitHub Pages 1분 무료 배포 가이드

1. **GitHub 저장소 생성:**
   - [GitHub](https://github.com) 로그인 후 **`New repository`** 생성 (이름: `pixel-dungeon-knight`, Public 설정).
2. **파일 업로드:**
   - 다운로드받은 `pixel-dungeon-knight.zip` 압축 해제 후 나온 **`index.html`**과 **`README.md`**를 GitHub 저장소에 드래그 앤 드롭 업로드 (`Commit changes`).
3. **GitHub Pages 활성화:**
   - 저장소 **`Settings` ➔ `Pages`**에서 Branch를 **`main`**(또는 `master`)으로 지정하고 **`Save`**.
4. **접속 링크 확인:**
   - 1~2분 후 생성되는 `https://내아이디.github.io/pixel-dungeon-knight/` 주소로 모바일/PC 어디서든 즉시 플레이 가능!
