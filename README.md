# 🗡️ 픽셀 던전 나이트 (Pixel Dungeon Knight)
> **마왕성 탈환: 16비트 레트로 도트 방치형 RPG 웹게임**

HTML5 Canvas & Web Audio API 기반으로 제작된 싱글 파일 브라우저 방치형 RPG입니다.  
별도의 백엔드 서버나 복잡한 설치 없이 브라우저 자체 로컬 스토리지(`localStorage`)와 암호화 백업을 지원합니다.

---

## 🎮 주요 게임 시스템 및 특징 (Features)

1. **레트로 16비트 도트 그래픽 & 사운드 (Retro Pixel Art & Chiptune)**
   - 캔버스 기반 프로시저럴 도트 그래픽 (용사의 전방 검기 베기 애니메이션, 타격 파티클, 폰트 데미지 팝업, 화면 진동 효과)
   - Web Audio API 기반 자체 8비트 칩튠 사운드 신시사이저 (외부 오디오 파일 로딩 제로, 소리 On/Off 지원)

2. **1,000 스테이지 & 20대 테마 던전**
   - 20개 대구역 (슬라임 초원부터 고블린 동굴, 오크 요새, 골렘 신전, 용들의 안식처, 마왕성 옥좌, 종말의 특이점까지 1,000 스테이지)
   - 8종 이상의 다채로운 몬스터 원형(슬라임, 고블린, 해골, 오크, 골렘, 원혼, 드래곤, 타락 기사, 마왕 등)과 구역별 동적 속성 컬러 팔레트
   - 스테이지 클릭 시 1000개 스테이지를 50개 단위로 렉 없이 둘러보는 **전체 스테이지 탐색 모달 (원클릭 현재/최고 위치 점프 지원)**
   - 화살표(`◀`, `▶`) 클릭 시 전투를 끊지 않고 **라운드 종료 후 자연스럽게 자동 전환**되는 예약 시스템

3. **성장, 장비 및 소환 시스템**
   - **기본 스텟 강화:** 공격력, 최대 체력, 초당 체력 회복, 치명타 확률, 치명타 피해, 공격 속도 (x1, x10, x100 일괄 강화)
   - **전투 스킬 연구:** 슬래시 웨이브(관통 검기), 메테오 스트라이크(광역 폭격), 버서커 광폭화(공속/치명타 극대화), 신성한 가호(보호막 & 즉시 치유)
   - **장비 시스템:** 4개 부위(무기, 갑옷, 투구, 반지), 7단계 등급(일반~초월), 개별 강화 및 5개 모아 상위 등급 일괄 합성, 최강 장비 원클릭 자동 장착
   - **소환 레벨 시스템:** 보석으로 1회/10회/30회 뽑기를 진행할수록 소환 경험치가 쌓여 소환 레벨(Lv.1~10)이 상승하며, 영웅·전설·신화·초월 장비 등장 확률이 대폭 증가

4. **모바일 최적화 편의 기능 (Utility)**
   - **AMOLED 번인 방지 절전 모드 (🌙):** 화면을 어두운 블랙 화면으로 전환하고 렌더링을 15 FPS로 낮추어 배터리 소모와 발열을 방지하면서 사냥은 100% 정상 진행
   - **전체화면 모드 (⛶):** 브라우저 주소창과 툴바를 숨기고 게임에만 몰입할 수 있는 전체화면 전환/해제 지원
   - **메인 타이틀 화면 & 전투 일시정지:** 타이틀 화면에서는 전투와 사운드가 정지되며, 저장된 모험 기록을 확인하고 시작 가능

5. **철저한 데이터 보존 & 암호화 백업**
   - 10초 주기 자동 저장 + 탭 닫기/이동 시 즉시 저장
   - **PDK-ENC 변조 방지 암호화 백업 토큰:** 복잡한 비밀번호 없이 클릭 한 번으로 암호화 세이브 코드 복사 및 복원 지원 (치트/에딧 방지 32비트 체크섬 탑재)
   - 최대 8시간 누적 오프라인 방치형 보상 지원
   - 향후 게임 패치나 업데이트 시에도 기존 세이브 100% 하위 호환 보장

## 🚀 GitHub Pages 1분 무료 배포 가이드 (가장 쉬운 방법)

GitHub Pages를 이용하면 별도의 서버 비용 없이 나만의 무료 웹게임 사이트를 운영할 수 있습니다.

1. **깃허브 저장소(Repository) 생성:**
   - [GitHub](https://github.com)에 로그인 후 우측 상단의 **`+` ➔ `New repository`**를 클릭합니다.
   - Repository name에 원하는 이름(예: `pixel-dungeon-knight`)을 입력하고 **Public**으로 설정한 뒤 **`Create repository`**를 누릅니다.
2. **파일 업로드:**
   - 생성된 화면 중간의 **`uploading an existing file`** 링크를 클릭합니다.
   - 다운로드받은 압축 파일의 압축을 푼 뒤, **`index.html`**과 **`README.md`** 두 파일을 마우스로 끌어다 놓고 하단의 **`Commit changes`** 버튼을 누릅니다.
3. **무료 웹 호스팅(GitHub Pages) 활성화:**
   - 저장소 상단 메뉴의 **`Settings` ➔ 좌측 사이드바 `Pages`** 메뉴로 이동합니다.
   - **Build and deployment** 섹션의 Branch 항목에서 `None`으로 되어 있는 부분을 **`main`**(또는 `master`)으로 변경하고 **`Save`**를 누릅니다.
4. **접속 링크 확인:**
   - 약 1~2분 뒤 새로고침하면 상단에 **`https://내아이디.github.io/pixel-dungeon-knight/`** 형태의 무료 웹게임 링크가 생성됩니다. 
   - 이 링크를 스마트폰이나 PC 브라우저에 입력하면 어디서든 바로 플레이하실 수 있습니다.
